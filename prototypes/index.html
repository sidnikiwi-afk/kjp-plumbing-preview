KJP Plumbing — Homepage Concepts

3 design directions for Kyle Benham

Start the dev server first: Run npm run dev in the kjp-plumbing folder, then click the links below.
Direction 1
Red Engine
Bold, industrial, high-energy. Full-width hero with plumber image bleeding edge-to-edge. Sharp edges, massive stats, sticky emergency CTA on mobile.
Kyle does emergency callouts and powerflushing — this feels urgent, confident, and no-nonsense. Red carries from his current brand.
Direction 2
Copper Pipe
Warm and editorial. Split-screen hero, alternating cream/navy sections, copper accents that reference the trade. Serif headings for authority.
Positions KJP as the experienced, trusted local choice. Copper literally references plumbing fittings. Editorial style makes credentials feel substantial.
Direction 3
Blueprint
Clean, modern, tech-forward. Typographic hero with grid-line background. Pill buttons, electric blue with lime accents. Everything feels fast and efficient.
Modern tradesmen need modern sites. Makes KJP stand out from every other plumber in Southampton running a generic template.
